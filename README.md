# Rust Exercises

A collection of Rust learning projects and exercises covering various concepts and practical applications.

## Projects

- **algo** - Algorithm implementations and exercises
- **calc** - Guessing game project  
- **encryption** - Encryption and cryptography exercises using the `ring` library
- **functions** - Rust functions and control flow exercises
- **server** - Web server built with Axum and Tokio frameworks
- **guess_game** - Interactive number guessing game

## Requirements

Rust 1.70+ with Cargo

## Running Projects

Navigate to any project directory and run:

```bash
cd <project_name>
cargo run
```

## Building

```bash
cargo build --release
```

Each project is a standalone Cargo package demonstrating different Rust concepts and features.
